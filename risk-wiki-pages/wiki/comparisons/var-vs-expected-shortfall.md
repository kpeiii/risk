# VaR 與 ES(CVaR)比較

資料來源:[Artzner et al. (1999)](../sources/artzner-1999-coherent-measures.md)、[Rockafellar & Uryasev (2000)](../sources/rockafellar-2000-cvar-optimization.md)、[Acerbi & Tasche (2002)](../sources/acerbi-2002-coherence-expected-shortfall.md)。

| 面向 | [VaR](../metrics/value-at-risk.md) | [ES / CVaR](../metrics/expected-shortfall.md) |
|---|---|---|
| 衡量什麼 | 最差 α 比例情境的**門檻** | 最差 α 比例情境的**平均損失** |
| 一致性 | 否(缺次可加性) | 是,任意分布皆成立(Acerbi & Tasche) |
| 看不看尾部嚴重程度 | 不看 | 看(取平均) |
| 對信賴水準 | 離散分布下可能不連續 | 連續且單調 |
| 分位數不唯一 | 有歧義(上/下分位數) | 定義不依賴分位數選擇 |
| 最佳化 | 用情境算時行為不佳、可能多局部極值 | 凸;可化為線性規劃(Rockafellar & Uryasev) |
| 常態分布下 | 與標準差成比例 | 同樣為 μ + c·σ,最佳組合與最小變異數相同(β ≥ 0.5、約束有效時) |
| 大小關係 | VaR ≤ CVaR | |
| 實務地位(論文時點) | 監管與業界普遍 | 尚未成為業界標準,在保險業漸受重視 |

## 同一資料的數字
20 情境(萬元):−30, −12, −8, −5, −3, −2, −1, 0, 0, 1, 1, 2, 2, 3, 3, 4, 5, 6, 8, 10(說明用範例)。

| 尾部機率 α | VaR | ES |
|---|---|---|
| 5% | 12 | 30 |
| 10% | 8 | 21 |

兩個三狀態債券(p = 3%、N = 100、α = 5%)的次可加性檢查見 [一致性風險度量](../concepts/coherent-risk-measure.md):VaR 為 0、0 → 合併 100(違反);ES 為 60、60 → 合併 100(滿足)。

## 如何選擇
- 要**報告一個門檻**、與既有監管指標對接 → 用 VaR,但明確說明其局限,不用來加總或分配限額。
- 要**控制尾部損失的大小**、分散化與集中度會影響結論、報酬不是常態、或需要最佳化大量情境 → 用 ES。
- 兩者可並列報告:VaR 說門檻,ES 說越過門檻後的平均損失。

## 爭議與不確定性
- Artzner 等人主張**拒絕** VaR 作為風險度量;Rockafellar & Uryasev 則是先承認 VaR 的缺陷,再提出實務可用的替代。三者沒有互相矛盾,差別在強調:公理分析、計算方法、一般分布下的定義。
- ES 優於 VaR 的論證主要來自**數學性質與小型範例**;已 ingest 論文都沒有提供大規模實證(如不同市場的回測結果、估計誤差的比較)。此點尚無已 ingest 論文涵蓋。
- **建議立場**:資本與限額類用途採 ES;VaR 作為補充報告。
- **信心程度**:中高(數學部分高;實證與回測部分低)。
